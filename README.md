## Hi, I'm Anannya Patil

I work on software systems that involve data, roles, permissions, and real-world workflows. I’m most interested in backend and system-oriented development, where logic, structure, and long-term correctness matter more than surface-level features.

## Flagship Projects (team-based)

### 🩺 Aarogya Pothi — Personal Health Record Manager (PHRM)
A secure, patient-centric digital health platform that enables controlled collaboration between patients, doctors, and researchers.

- Patient-owned medical records with granular, revocable consent  
- Separate patient, doctor, and researcher modules with role-based access  
- Symptom logging for long-term pattern analysis  
- Secure report uploads and controlled data sharing  
- Research access via anonymized, consent-approved datasets  

**Tech:** Python (Flask), MySQL, HTML/CSS/JS, Bootstrap, Firebase Authentication

---

### 🛡️ Zone-Based Crowd Safety & Alert System
A zone-driven public safety platform designed for large-scale events such as the Kumbh Mela.

- Event areas divided into managed GPS zones with local officials  
- Zone-specific alerts instead of blanket mass notifications  
- Two-way communication between attendees and officials  
- Offline resilience using SMS fallback and cached maps  
- QR-based onboarding without mandatory app installation  

**Tech:** PHP, MySQL, HTML/CSS/JS, Service Workers, Web Push, QR libraries

---

### 💻 Lab Management System
An admin-focused system for managing laboratory devices, issues, and maintenance lifecycles.

- Full device lifecycle tracking (allocation, repair, retirement)

- Visual lab layouts and admin-only dashboards  

**Tech:** HTML, CSS, JavaScript, Firebase, MySQL
